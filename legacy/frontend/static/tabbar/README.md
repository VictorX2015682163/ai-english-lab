# TabBar 图标说明

此目录需要放置底部导航栏的图标文件。

## 需要的图标文件

请准备以下 8 个图标文件（建议尺寸：81x81px，PNG 格式）：

### Home（首页）
- `home.png` - 未选中状态（浅灰色线条图标）
- `home-active.png` - 选中状态（墨绿色线条图标）

### Public（公立）
- `public.png` - 未选中状态（浅灰色书本线框图标）
- `public-active.png` - 选中状态（墨绿色书本线框图标）

### International（国际）
- `international.png` - 未选中状态（浅灰色地球线框图标）
- `international-active.png` - 选中状态（墨绿色地球线框图标）

### My Learning（学习）
- `learning.png` - 未选中状态（浅灰色进度/图表线框图标）
- `learning-active.png` - 选中状态（墨绿色进度/图表线框图标）

## 图标要求

- **风格**：细线条、无填充、极简风格
- **颜色**：
  - 未选中：#B0B0B0（浅灰）
  - 选中：#2F5D62（墨绿色）
- **尺寸**：建议 81x81px（uni-app 推荐尺寸）

## 临时方案

如果暂时没有图标文件，可以：
1. 使用在线图标库（如 iconfont、Feather Icons）下载对应图标
2. 使用设计工具（如 Figma、Sketch）创建简单线条图标
3. 暂时使用文字替代（需要修改 pages.json 中的 tabBar 配置）
